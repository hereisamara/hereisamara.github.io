# Khin Eaindray Htun - AI & Data Portfolio

This customized portfolio combines:
- minimal neobrutalism
- light paper-like background
- restrained sage accent
- handwritten annotations
- sketch-style arrows and doodles
- hard borders/shadows
- recruiter-friendly data portfolio structure

## Files
- `index.html` — content and page structure
- `style.css` — theme and responsive design
- `script.js` — project filtering and Chart.js chart
- `README.md` — setup notes

## Design system
The main colors are at the top of `style.css` under `:root`.

The handwritten font is **Caveat**, while the main UI uses **Inter**.

## Design principle
Use handwriting as annotation, not body text. Keep:
- titles
- data
- metrics
- navigation
- project descriptions

in the clean sans-serif font.

Use handwritten notes only for:
- comments
- arrows
- callouts
- tiny human observations
- labels around diagrams
