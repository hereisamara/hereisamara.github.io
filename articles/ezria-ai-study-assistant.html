Ezria — AI-Integrated Study Assistant

One learning workspace for organizing study materials, managing schedules, planning exams, tracking tasks, and measuring progress.

Khin Eaindray Htun · Kyaw Swar Hein School of Information Technology · KMUTT

Ezria—Education Zone for Resourceful Integration & Assistance—is an AI-integrated learning assistant created to reduce the friction of using separate applications for materials, schedules, exam planning, tasks, and study-progress tracking.

The problem

Students often split their learning workflow across document storage, calendars, task managers, and revision tools. Ezria was designed around a single product surface so the information needed for studying and the actions used to plan it stay connected.

The AI assistant

The assistant layer uses Python with Gemini and LangChain. Its retrieval-augmented workflow brings relevant document context into question answering, helping responses stay connected to the study material supplied by the learner.

Application architecture

The mobile experience was built with Dart and Flutter. Go and Python services supported the backend through Fiber and Flask, separating the application APIs from the AI-oriented workflow.

Data layer

MongoDB and Firebase supported application storage, user data, and authentication needs. This gave the team a practical foundation for keeping learning content and account-level application data available across the product.

Delivery environment

Services were containerized with Docker and Docker Compose, routed through NGINX, and hosted on an Ubuntu-based SIT virtual machine. The development workflow also used GitHub, Visual Studio Code, Google Colab, Android Studio, and Postman.

Product design

Figma, Canva, Miro, Inkscape, and DaVinci Resolve supported the interface, diagrams, presentation, graphics, and demonstration materials used to communicate the project as a complete product.
